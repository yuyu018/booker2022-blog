# 布克小姐網站｜寫稿人手冊

這份手冊給負責寫文章、改頁面文字的夥伴。**完全不需要懂程式**，也不用在自己的電腦安裝任何東西，只要有瀏覽器和一個 GitHub 帳號。

---

## 一、開始之前

1. 網站主人會寄一封 GitHub 邀請信給你 → 點信裡的 **Accept invitation**（接受邀請）。
2. 之後所有工作都在這個網址進行：

   **https://missbooker.com/keystatic**

3. 第一次進入會要求你用 GitHub 帳號登入，按 **用 GitHub 帳號登入** 並同意即可。

---

## 二、後台長什麼樣子

左邊是選單，分成三區：

| 區塊 | 裡面有什麼 |
| --- | --- |
| **文章** | 所有文章。新增、修改、刪除都在這裡 |
| **頁面文字** | 首頁、關於頁、服務項目頁、聯絡資訊頁、文章列表頁的所有文字 |
| **全站設定** | 導覽列、頁尾、四大分類的名稱與說明 |

每個欄位下面都有一行灰色小字，說明這段文字會出現在畫面的哪裡。

---

## 三、寫一篇新文章

1. 左邊點 **文章** → 右上角 **新增**。
2. 填欄位：

   - **標題**：文章名稱。
   - **網址名稱（Slug）**：這篇文章的網址，建議用英文或數字，例如 `my-first-post`。**存檔後就不要再改**，否則舊連結會失效。
   - **摘要**：列表上顯示的簡介，大約 60–90 字。
   - **發布時間**：決定文章的日期與排序。
   - **分類**：金錢／生活／閱讀／自我成長，四選一。
   - **標籤**：可留空。
   - **主視覺圖**：文章開頭的大圖，可留空。
   - **內文**：直接打字。上方工具列可以做標題、粗體、引用、清單、插圖。

3. 右上角 **儲存**。

## 四、修改頁面文字

1. 左邊 **頁面文字** → 選一個頁面。
2. 改完 → **儲存**。

幾個常見的：

- 首頁大標、按鈕文字、三個數字 → **首頁**
- 自我介紹、三段故事、三個信念 → **關於頁**
- 合作方式 → **服務項目頁**
- 電子郵件、社群連結、聯絡表單文字 → **聯絡資訊頁**
- 導覽列標語、頁尾文字 → **網站共用文字**

> 首頁「三個數字」中，數字欄填 `auto` 會自動顯示目前的文章總數，不用手動維護。

---

## 五、存檔之後會發生什麼事

**按下「儲存」不會馬上更新網站。**

你的修改會存成一份「待審稿」送給網站主人，她確認後才會正式上線（通常幾分鐘內就會看到）。

畫面上如果出現 **送出審稿** 的按鈕，按下去就對了。

---

## 六、注意事項

1. **舊文章（2026 年 9 月以前從 Facebook 搬過來的）盡量不要用後台改。**
   那些文章保留了原本 Facebook 的短句斷行，用後台編輯器打開再存檔，斷行方式可能會跑掉。
   真的要改，請先告訴網站主人。

2. **網址名稱（Slug）存檔後不要改**，文章已經被分享出去的連結會失效。

3. **不要刪除文章**，需要下架請先跟網站主人說。

4. 文字裡不要出現網站主人的本名，一律使用筆名「布克小姐」。

5. 存檔失敗、畫面卡住 → 重新整理頁面再試一次；還是不行就截圖給網站主人。
