# 寫稿後台上線設定（網站主人專用）

程式碼已經改好，剩下的是帳號與設定。全部免費，不需要付費方案。

依序做完 1 → 5 就能讓寫稿人用瀏覽器上工。

---

## 步驟 1：推送程式碼

```bash
git add -A && git commit -m "Add Keystatic CMS for page text and posts" && git push
```

推送後 Vercel 會自動部署。**這次部署多了伺服器功能（後台登入用），第一次部署請確認 Vercel 沒有把 Output Directory 手動指定成 `dist`**；保持「Framework Preset: Astro、其他留空（自動偵測）」即可。

---

## 步驟 2：建立 GitHub App（給後台登入用）

打開 <https://github.com/settings/apps/new>，填：

| 欄位 | 填什麼 |
| --- | --- |
| GitHub App name | `Booker CMS`（名稱不能跟別人重複，可加數字） |
| Homepage URL | `https://missbooker.com` |
| Callback URL | `https://missbooker.com/api/keystatic/github/oauth/callback` |
| Request user authorization (OAuth) during installation | **勾選** |
| Webhook → Active | **取消勾選** |

Repository permissions 設定三項：

- **Contents**：Read and write
- **Pull requests**：Read and write
- **Metadata**：Read-only

「Where can this GitHub App be installed?」選 **Only on this account**，按 **Create GitHub App**。

建好之後在這一頁做三件事：

1. 記下 **Client ID**。
2. 按 **Generate a new client secret**，把產生的字串複製下來（只會顯示一次）。
3. 記下網址列的 App 代號，也就是 `https://github.com/apps/<這一段>`。
4. 左邊 **Install App** → 安裝到 `booker2022-blog` 這個 repo。

---

## 步驟 3：在 Vercel 加環境變數

Vercel → 專案 → Settings → Environment Variables，新增四個（都選 All Environments）：

| 名稱 | 值 |
| --- | --- |
| `KEYSTATIC_GITHUB_CLIENT_ID` | 步驟 2 的 Client ID |
| `KEYSTATIC_GITHUB_CLIENT_SECRET` | 步驟 2 的 client secret |
| `PUBLIC_KEYSTATIC_GITHUB_APP_SLUG` | 步驟 2 的 App 代號 |
| `KEYSTATIC_SECRET` | 一串隨機字元，用下面指令產生 |

```bash
openssl rand -hex 32
```

加完後回到 Deployments → 最新那筆 → **Redeploy**（環境變數要重新部署才會生效）。

---

## 步驟 4：讓寫稿人進得來，但改不動正式版

1. **邀請他**：GitHub repo → Settings → Collaborators → Add people → 權限選 **Write**。
2. **保護 main 分支**（這一步就是「推送我這邊做」的關鍵）：
   repo → Settings → Rules → Rulesets → New branch ruleset
   - Target branches：`main`
   - 勾選 **Require a pull request before merging**
   - Bypass list 加上自己（Repository admin），這樣你仍可直接推送

   設定完成後，寫稿人在後台存檔只能開成 `draft-xxx` 分支並送出 pull request，碰不到正式網站。

---

## 步驟 5：你的審稿流程

1. 寫稿人送審後，GitHub 首頁 **Pull requests** 會出現一筆。
2. 點進去 → **Files changed** 看改了什麼。
3. Vercel 會自動給一個預覽網址，可以先看實際畫面。
4. 沒問題就按 **Merge pull request** → 正式網站幾分鐘後更新。
5. 不想要就按 **Close pull request**。

## 附註

- 自己要改東西時，在電腦上跑 `npm run dev`，打開 <http://localhost:4321/keystatic>，是**本機模式**，存檔直接寫進檔案，不用登入 GitHub。
- 寫稿人的操作說明在 [`docs/寫稿人手冊.md`](./寫稿人手冊.md)，可以直接把內容貼給他。
- 後台網址 `https://missbooker.com/keystatic` 要先用 GitHub 登入才能操作；能不能存檔由 repo 權限決定，沒有被邀請的人改不了任何東西。已在 `robots.txt` 擋掉搜尋引擎收錄。
